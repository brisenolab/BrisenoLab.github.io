## About the Lab

The Alcalá Briseño Lab investigates the ecology and evolution of plant-associated viruses and microbial communities using molecular biology, genomics, bioinformatics, and ecological modeling.

Current research interests include:

- Plant virology
- Viral ecology
- Viromes
- Metabarcoding
- Microbiome ecology
- Disease ecology
- Forest pathology
- Bioinformatics
- High-throughput sequencing
- Genomic epidemiology
